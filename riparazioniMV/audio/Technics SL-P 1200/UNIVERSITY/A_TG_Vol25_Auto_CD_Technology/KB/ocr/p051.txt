MASH Block

The MASH block consists of many noise
shapers connected in series. The noise
shapers include the signal and double
integration types.

* Single integration noise shaper

The single integration noise saper uses
only a single integrator for noise
shaping as shows in figure 5-12. The
block marked "Q" in this figure is a
local quantizer which adds quantization
error to the input data. The relationship
between output (Y) and input (X) for this
type of noise shaper is:

Y=X+(1-2Z ). Vq............ (1)

The quantization error, Vq is a random

value and the factor (1 - Z ) in this
equation represents a differentiation
respons. Eq. (1) tells us, therefore,

that the spectrum of the quantization
error, Vq in the single integration noise
shaper has an attenuation slope of -6
dB/oct toward lower frequencies as shows
in figure 5-14.
