## Rilevanza SL-P1200 (ALTA per Type C e parte di Type A)
- Type C = AN8370S + AN8371S + MN6617 = stessa catena del P1200 -> C4-1..C4-5 pp.57-90: teoria completa AN8370S (control logic, APC, RF/dropout, auto focus, TE/kick/hold, drive, relazione con CPU), AN8371S (EFM/PCK), MN6617 (registrazione, riproduzione, periferiche, CLV), audio.
- Type A usa AN8290S spindle driver = SL-P1200 IC501 (p.5) e MN6617.
- Troubleshooting con flow chart TOC read/play (pp.115-116, 123-124, 127-128): checklist laser -> focus -> spindle -> focus loop -> tracking loop -> traverse -> DSL -> AGC/ARF -> SRF -> PCK sync -> CLV phase comparison -> EFM/PCK -> audio. Valori: AN8371S/LSI pin 78 FPC 2.4-2.5V a PLL agganciato.
- Pulizia lente: kit SZZP1038C (pp.117-118).
- I riferimenti IC (IC101, IC301, IC401...) sono quelli delle autoradio, NON del P1200.
