6) Spindle Servo Control

The spindle servo control logic has four
modes: CVL, 11T, 6T, and 6T break modes.

(1) 11T Mode
This mode is selected when the tracking
servo is active (TRON = low) and the PLL
is unlocked.

Since XCK=16.9344 MHz, the SRF frame
sync signal pulse width is approximately
43XCK.

(2) CLV Mode

The CLV mode is selected if the PLL is
locked when the spindle motor rotation
rate is less than approx, 4.6% of the
normal rotation rate. Either the 11T or
CLV mode is automatically selected

provided the tracking servo is active
(TRON = low).

The device compares the FCLK's phase
with CLDCK's phase by comparing the
value of the RAM read counter (which is
synchronous with the reference frame
sync signal (FCLK) with that of the RAM
write counter (which is synchronous with
the frame sync signal, CLDCK, extracted
from the EFM pattern), and provides a
phase error signal at its EC pin.
