| 4. Servo Gain Adjustment

Procedures

4

1. Connect the 5-pin code supplied

with this unit to the 5-pin
connector on the rear panel.
2. Disconnected the short—jumper

connected to the servo adjustment
connector on a CD player and
connect the other end of the 5-pin
code to the servo adjustment
connector.

3. Set the modes selector switch @
on the unit panel to position "2"
(DEFEATED) and turn on the CD
player to read the TOC.

Focus Servo Gain Adjustment

1. Adjust the input level for the CD
player with the osc level.
controller 1) on the unit
panel.(Refer to the service manual
for the input level).

2. Select the frequency of the
oscillator with the frequency
switches (@ and @). (Refer to

service manual for the frequency).

3. Set the mode selector switch @ on
the panel of the unit to position
"3" and adjust the semi fixed
volume for focus gain control on
the CD player so that the LED
"GOOD" on the servo gain INDICATOR
panel lights up.

NOTE

First adjust the volune for focus
gain control so that LOW LED on the
servo gain INDICATOR panel lights

up and then make further
adjustments until the GOOD LED
lights up.
