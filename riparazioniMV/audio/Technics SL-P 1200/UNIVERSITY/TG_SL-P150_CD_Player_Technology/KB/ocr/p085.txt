(ad) ATT

This command allows the D/A output data
to be attenuated. It is effective for
both parallel DAO - DA15 outpou and
serial SRDATA output.

Output is attenuated -12dB when ATT is
set high. And attenuation is released
when ATT is set low.

(e)MUTE

This command allows the D/A output data
to be muted in case of dropout. The D/A
output is muted to logical all zeros
when MUTE is set high, muting is cleared
when it is set low (only when DMUTE=low)

The DMUTE pin may be used for direct
muting since it is logically OR'’ed with
the MUTE signal.

negative edge of the clock applied to
the ITC pin (Track Counter Input). The

TCO (internal) is set low when the ITC
