@ Emphasis indicator: Note: 3
Lights when a disc containing pre-emphasis is played.

Note-3:

Pre-emphasis:
In order to further improve the S/N ratio of compact
discs, some discs include a degree of emphasis in the
high range called pre-emphasis. If these discs are
played without any compensation, the high range will
be unnaturally strong. Therefore, a corresponding
amount of de-emphasis is needed to obtain the proper
response. The de-emphasis circuitry of this unit is

automatically activated when a disc having pre-emph-
asis is played.

® Music scan button
When this button is pressed, the first ten seconds (or the
specified time) of each track on the disc or each programmed
track is played. This is very useful for quickly ascertaining the
contents of a disc.
The time that each track is played can be adjusted from 1 to
99 seconds by using the numeric buttons.
(programmable music scan function)

@® Remaining time button
Press this button while a disc is being played to display
the remaining playing time (min. and sec.) of a disc.
When this button is pressed, the time indicator lights and the
display switches to the remaining time display mode. Press
this button again to return to the elapsed playing time mode.

@ A-B repeat button

Press this button to use the A-B repeat mode.

The first time this button is pressed (‘' a > " repeat indicator
lights), the starting point of the disc section to be played
repeatedly is set. The second time this button is pressed
(* (AGs)” repeat indicator lights), the ending point of the
repeat section is set. The section of the disc between these
two points will now be played repeatedly until this button is
pressed a third time to cancel the A-B repeat mode. This
function is very convenient because it allows you to specify a
section to be played repeatedly while listening to a disc.
