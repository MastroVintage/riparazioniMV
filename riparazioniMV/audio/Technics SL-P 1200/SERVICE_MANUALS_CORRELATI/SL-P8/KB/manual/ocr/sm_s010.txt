e To enter a program during disc play

A new program can be entered while a disc is being played
even if the program clear button is not pressed. When the
new program is entered, the previous programs will still be
erased and disc play based on the new program will begin.

Note:

@ When entering a program during disc play, the
Program buttons must be operated without
interruption. If there is a gap of more than 20
seconds between the time two program buttons
are pressed, the new program will not be entered
and disc play will continue in the normal manner.

e To cancel a program

Press the program clear button. The program will be cleared
from the memory and disc play will continue in the normal
manner,
